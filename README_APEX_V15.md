# Portfolio APEX V15

本版基于 APEX V14 完整工程继续精修，保留原有四个项目与所有素材。

## 本版调整
- Cover：`portfolio` 文字卡片增加持续悬浮动画；悬停时整体放大、上浮更明显。
- About：个人信息卡片改用与顶部项目导航相同的半透明背景模糊语言；个人信息卡片与肖像的悬停浮起/放大加强。
- Apex Cover：`Apex Vitalis` 改为单行标题，并调整字距与字号比例以适配单行展示。
- Apex Structure：改为“左侧说明 / 中央结构图 / 右侧两个部件细节”的三列构图，中央结构图放大并居中。
- Apex Closing：标题改为四排；展开/折叠两种状态以叠层方式重新定位，整体更紧凑。
- Moody Cover：三个机器人恢复为较小、三角形构图，并稍微放大、缩短彼此间距。

## 启动
```bash
npm install
npm run dev
```

作品集 About 页面 V5

这是可直接替换你现有 portfolio 项目的完整项目文件（不含 node_modules）。

使用方法：
1. 先备份你电脑里原来的 portfolio 文件夹。
2. 解压本压缩包，得到 portfolio 文件夹。
3. 用解压后的 portfolio 文件夹替换/覆盖你现在项目对应文件。
4. 保留你电脑原项目里的 node_modules 不动也可以；本包没有包含 node_modules。
5. 在 VS Code 终端运行：npm run dev
6. 打开终端显示的 localhost 地址。

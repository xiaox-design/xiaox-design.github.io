# Portfolio Apex V18

- Cover 作品集标题卡片 hover 放大过渡进一步放缓并平滑。

- Apex 尾页展开/折叠产品状态重新调整为更明确的高低、左右层次。
- Moody 首图三个机器人恢复为用户给出的三角形布局，并放大实际可见图像而非单纯扩大触控区域。

- Wash Well 下部板块收紧顶部留白，避免出现大块空白。
- 四个产品详情页尾部右下角统一改为“返回作品目录页”，并保留左下角邮箱。

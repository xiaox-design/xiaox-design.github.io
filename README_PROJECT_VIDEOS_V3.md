# Portfolio — Project Videos V3

本版本在上一版 `portfolio_apex_video_v2` 的基础上新增两个产品视频：

- `src/assets/project-video/moody-product-film.mp4` → MOODY（第二个作品）
- `src/assets/project-video/gradient-product-film.mp4` → GRADIENT（第三个作品）

两个视频都直接嵌入对应产品详细页，位置与 Apex Vitalis 的产品视频一致：
`封面页 → 产品视频 → 项目背景`。

视频默认静音自动播放，支持浏览器原生播放控制，并提供首帧海报图。
